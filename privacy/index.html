Privacy

This website uses Umami Cloud for limited audience statistics: page visits, broad device and location information, and interactions with research links. Statistics are used to understand how this personal research website is read. The dashboard is private.

Tracking runs without analytics cookies, advertising profiles, cross-site identifiers, or session recording. URL parameters and fragments are removed, referring URLs are reduced to their origin, and no names, email addresses, form contents, or custom visitor identifiers are sent by this site's tracker. Connection metadata is processed by Umami to derive approximate location and pseudonymous session statistics; its documentation states that visitor IP addresses are not stored in analytics data.

The current Hobby plan retains analytics for six months. See Umami’s privacy policy. GitHub also processes requests to host this website under its own privacy statement.

Do Not Track and Global Privacy Control are respected before loading the analytics service. You can also save a preference for this browser below.

JavaScript is required to save a browser preference; audience statistics do not run while JavaScript is disabled.
